# 챙겨요 (chaenggyeo)

> "집에 가면 체육복" — 한 마디만 하면, 그 장소에서 캐릭터가 챙겨 준다.

장소에 가서 해야 할 일을 자꾸 까먹는 문제를 해결하는 위치 기반 리마인더 앱.

- **말 한마디로 등록**: "집에서 체육복", "퇴근할 때 우산", "집에 가는 길에 물"
- **알맞은 순간에 알림**: 도착할 때 / 떠날 때 / 가는 길에 들를 곳 근처에서
- **귀여운 캐릭터**: 위젯·잠금화면·다이내믹 아일랜드에서 상황을 보여 줌
- **앱을 안 열어도 됨**: Siri, 위젯, 액션 버튼으로 바로 입력
